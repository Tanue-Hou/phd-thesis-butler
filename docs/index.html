四个工作流

从研究方向到俄语论文，覆盖论文写作全流程

①
俄语润色与表达优化
已有俄语段落或全文时，优化学术表达、段落衔接、降低机器感。16,722 条句式模板从 2,118 篇俄罗斯学位论文蒸馏而来，三层回退检索确保命中。
assets + retrieve_templates.py
②
论文规划与结构设计
从研究方向自动生成完整论文结构：章节设计（6大学科×5种模式）、方法论路线选择、实验方案设计、各章节写作功能定义——不只是大纲，而是每章该写什么、怎么展开、如何闭环。
planning_layer + discipline assets
③
文献调研与论文对比
搜索 DisserCat、eLIBRARY、CyberLeninka、OpenAlex 等俄罗斯本土文献源；支持直连本地 Zotero 库（无需手动导出）；自动对比 10-30 篇同方向论文的结构、方法、验证方式，生成 12 节报告 + 推荐大纲。
research_layer + landscape/
④
证据检查与引用修复
逐句检测章节草稿中的论断是否缺引用，12 种证据角色（background、research gap、benchmark 等），自动标注 covered / missing / not_needed，推荐补充文献类型。
evidence_layer + binding/gap scripts

核心能力

不只是句式库，而是一套完整的论文写作智能体系统

🔍
俄罗斯学位论文搜索
直连 DisserCat（俄罗斯学位论文库）、eLIBRARY / RINC（核心期刊）、CyberLeninka（开放获取），全方位覆盖俄罗斯本土文献。
📚
Zotero 私有库直连
通过本地 API 读取 Zotero 元数据、标签、集合、已索引全文，按条件搜索后直接进入论文对比分析——不需要手动导出文献。
🏗
同方向论文结构对比
从公开来源或 Zotero 获取同方向论文，自动聚类主题、对比章节结构模式、方法论路线和验证方式，输出结构化报告 + 推荐大纲（可直接进入规划工作流）。
📝
16,722 条俄语句式模板
从 МГТУ / МГУ / СПбГУ 2,118 篇学位论文中蒸馏出的原生俄语句式，覆盖引言到结论全部章节，DISCIPLINE → CLUSTER → GLOBAL 三层回退检索。
🧩
论文全流程规划
从研究方向生成完整论文结构：整体章节设计（6 大学科 × 5 种模式）、方法论路线、实验方案、各章节写作功能定义和输入输出、逻辑闭环检查。
✅
引用缺口检测
逐句分析章节草稿中每个论断的引用状态，12 种证据角色自动分类，生成可读报告指出现有证据缺口并推荐补充文献类型。
