# v5.3 Evidence-Aware Writing — 实施路线图

> **定位：** 把"查到的文献"变成"章节里可用的证据"。
> v5.2 解决"文献怎么进来"，v5.3 解决"文献如何服务写作"。

---

## 总体架构

```text
Research Layer v5.2          Evidence Layer v5.3           Writing Layer（已有）
检索策略 / 文献标准化       证据角色识别 / 章节绑定      章节规划 / 段落润色
综述 brief                  缺口检测                     俄语表达模板
       ↓                            ↓                            ↓
  查到的文献              →    章节可用的证据          →    写作/润色输出
```

## 依赖关系图

```text
v5.3.0 (Evidence Contract)
  ┊
  ├──→ v5.3.1 (Chapter Evidence Binding)
  │       ┊
  │       └──→ v5.3.3 (Evidence-Aware Polishing) ←──┐
  │                                                  │
  └──→ v5.3.2 (Citation Gap Detection) ──────────────┘
                                                      │
                                                      ↓
                                               v5.3.4 (Validation)
                                                      │
                                                      ↓
                                               v5.3 Final Release
```

v5.3.0 必须先做（schema是后面所有脚本的依赖）。
v5.3.1 和 v5.3.2 可并行（脚本互相独立，都依赖schema）。
v5.3.3 依赖 v5.3.1 + v5.3.2 完成后才能做。
v5.3.4 是最后的验证收尾。
