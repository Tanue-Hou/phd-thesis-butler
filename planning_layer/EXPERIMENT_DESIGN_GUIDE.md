# РУКОВОДСТВО ПО ДИЗАЙНУ ЭКСПЕРИМЕНТОВ — PhD Thesis Butler v3.3.5

## Назначение

Структурированный подход к планированию, проведению и описанию экспериментов в диссертации.

## Типы экспериментов

### По среде проведения
- **Лабораторные** — контролируемые условия, воспроизводимость
- **Полевые/натурные** — реальные условия, экологическая валидность
- **Компьютерные (симуляции)** — моделирование, параметрические исследования
- **Валидационные** — проверка модели на реальных данных

### По цели
- **Поисковые** (exploratory) — определение факторов
- **Подтверждающие** (confirmatory) — проверка гипотез
- **Сравнительные** — бенчмаркинг методов
- **Параметрические** — исследование влияния параметров

## Этапы дизайна эксперимента

### 1. Формулировка цели
- Какой вопрос отвечает эксперимент?
- Какая гипотеза проверяется?
- Какой результат считается подтверждением?

### 2. Определение переменных
- **Независимые** — управляемые параметры
- **Зависимые** — измеряемые результаты
- **Контролируемые** — фиксируемые условия
- **Помеховые** — потенциальные искажения

### 3. Выбор протокола
- Количество повторов (statistical power)
- Порядок проведения (randomization, blocking)
- Контрольные группы/состояния
- Размер выборки (sample size calculation)

### 4. Инструменты и оборудование
- Измерительные приборы, калибровка
- Программное обеспечение, версии
- Стенды, макеты, испытательные системы

### 5. План анализа данных
- Статистические критерии
- Уровень значимости (α)
- Корректировки на множественные сравнения
- Эффект-сайз (effect size)

## Описание эксперимента в тексте

```
## Эксперимент N: [Название]

**Цель**: ...
**Гипотеза**: H₀: ... / H₁: ...
**Оборудование**: ...
**Протокол**: ...
**Переменные**: НЗ = ..., З = ..., Контролируемые = ...
**Количество повторов**: N = ...
**Статистический метод**: ...
**Критерий успеха**: ...
**evidence_count**: { "preliminary": N, "confidence": "pending|low|medium|high" }
```

## Ошибки дизайна

- Недостаточное количество повторов → low statistical power
- Отсутствие контрольной группы → невозможно отделить эффект
- Систематическая ошибка → смещённые результаты
- P-hacking → ложноположительные результаты
- Отсутствие предварительного плана → HARKing (Hypothesizing After Results are Known)

## evidence_count для экспериментов

Каждый эксперимент должен содержать:
- `evidence_count.value` — количество подтверждающих наблюдений/повторов
- `evidence_count.confidence` — `"pending"` до завершения, затем `"low"` / `"medium"` / `"high"`
- После завершения: p-value, доверительный интервал, effect size
