# ПЛАНИРОВЩИК ДИССЕРТАЦИИ — PhD Thesis Butler v3.3.5

## Обзор

Планировщик диссертации — центральный документ управления процессом написания кандидатской/докторской диссертации. Связывает структуру, методологию, логику и экспериментальный дизайн в единый план.

## Стадии планирования

### 1. Определение темы и гипотезы
- Сформулировать проблему исследования (research gap)
- Определить гипотезу(-ы) — проверяемые утверждения
- Оценить новизну и практическую значимость
- Зафиксировать целевую аудиторию (ВАК, журнал, конференция)

### 2. Обзор литературы
- Систематический поиск по ключевым словам
- Классификация источников: теория, метод, эксперимент, обзоры
- Построение карты связей между работами
- Выявление незаполненных ниш (evidence_count: отслеживать количество проанализированных источников с уровнем достоверности)

### 3. Выбор методологии
- Определить кластер дисциплины → см. соответствующий файл кластера
- Выбрать паттерн структуры → см. STRUCTURE_PATTERNS.json
- Согласовать с научным руководителем → см. supervisor_report_template.md

### 4. Планирование экспериментов
- Использовать experiment_plan_template.md
- Для каждого эксперимента зафиксировать:
  - Цель, гипотезу, переменные
  - Оборудование/данные/инструменты
  - Ожидаемые результаты и критерии успеха
- evidence_count: количество повторов, p-value, доверительные интервалы

### 5. Структурирование глав
- Использовать chapter_plan_template.md
- Для каждой главы определить: содержание, объём, связи с другими главами
- Привязать к логическому потоку → LOGIC_FLOW_GUIDE.md

### 6. Написание и ревизия
- Черновик каждой главы отдельно
- Внутренняя когерентность (логические связи)
- Проверка на плагиат
- Форматирование по требованиям ВАК/вуза

## Поле evidence_count

Поле `evidence_count` используется для количественной оценки достоверности:
- `"pending"` — данные ещё не собраны
- Числовое значение — количество подтверждающих источников/экспериментов
- Уровень достоверности: `"low"` | `"medium"` | `"high"` | `"confirmed"`

Применяется во всех JSON-паттернах и учитывается в гайдах при оценке обоснованности выборов.
