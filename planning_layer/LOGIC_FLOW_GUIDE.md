# РУКОВОДСТВО ПО ЛОГИЧЕСКОМУ ПОТОКУ — PhD Thesis Butler v3.3.5

## Назначение

Обеспечивает непротиворечивую логическую связь между всеми частями диссертации: от постановки проблемы до выводов.

## Базовый логический поток

```
Проблема → Гипотеза → Цели → Задачи → Методы → Результаты → Выводы
    ↑                                                          ↓
    ←←←←←←←←←←←←←← Обсуждение ←←←←←←←←←←←←←←←←←←←←←←←←←←←←←
```

## Принципы логической когерентности

### 1. Дедуктивный поток
- Общая теория → частное применение →验证
- Подходит: ENGINEERING_CONTROL, COMPUTER_AI, NATURAL_SCIENCE

### 2. Индуктивный поток
- Наблюдения → паттерны → теория
- Подходит: HUMANITIES_ARTS, LIFE_MEDICAL

### 3. Гипотетико-дедуктивный поток
- Гипотеза → следствие → проверка → подтверждение/опровержение
- Подходит: все кластеры, наиболее универсальный

## Связность глав

### Внутри главы
- Каждый раздел логически вытекает из предыдущего
- Формулировки-связки: «В предыдущем разделе было показано...»
- Нумерация уравнений, рисунков, таблиц сквозная

### Между главами
- Глава N ссылается на результаты главы N-1
- Глава N обосновывает необходимость главы N+1
- evidence_count: отслеживать количество перекрёстных ссылок для оценки связности

### «Золотая нить» (Golden Thread)
- Проблема исследования → пронизывает ВСЕ главы
- Каждая глава отвечает на часть проблемы
- Выводы замыкают проблему

## Проверка логического потока

Чек-лист:
- [ ] Гипотеза выводится из обзора литературы
- [ ] Задачи декомпозируют цель на проверяемые части
- [ ] Методы соответствуют задачам
- [ ] Результаты адресуют задачи напрямую
- [ ] Обсуждение интерпретирует результаты через призму гипотезы
- [ ] Выводы подтверждают/опровергают гипотезу
- [ ] Практические рекомендации следуют из выводов

## Антипаттерны

- **Разрыв**: результаты не связаны с гипотезой
- **Подмена**: в выводах обсуждается не то, что исследовалось
- **Цикл**: глава A ссылается на B, B на C, C на A без якоря
- **Провисание**: задача поставлена, но не решена ни в одной главе

## evidence_count для логической связности

- Подсчёт перекрёстных ссылок между главами
- Минимум 3 ссылки на каждую предшествующую главу
- Уровень достоверности связности: оценка количества логических «разрывов» при ревизии
