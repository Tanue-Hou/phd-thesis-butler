# РУКОВОДСТВО ПО МЕТОДОЛОГИИ — PhD Thesis Butler v3.3.5

## Назначение

Руководство помогает выбрать, обосновать и описать методологию исследования в зависимости от дисциплинарного кластера.

## Типы методологий

### Количественные
- Экспериментальный метод (лабораторный, полевой, натурный)
- Моделирование (математическое, компьютерное, физическое)
- Статистический анализ (ANOVA, регрессия, байесовский вывод)
- Численные методы (CFD, FEM, метод конечных разностей)

### Качественные
- Тематический анализ
- Этнография
- Анализ нарративов
- Гrounded theory

### Смешанные
- Последовательный объяснительный дизайн
- Параллельный конвергентный дизайн
- Встроенный дизайн

## Обоснование методологии

Каждый выбор методологии должен включать:
1. **Релевантность** — почему метод подходит для данной задачи
2. **Валидность** — внутренняя и внешняя
3. **Надёжность** — воспроизводимость результатов
4. **Ограничения** — что метод НЕ позволяет сделать

## evidence_count в методологии

При обосновании метода необходимо указать:
- Количество работ, успешно применивших данный метод к аналогичным задачам
- Уровень достоверности: `"pending"` до сбора данных, затем числовое значение
- Пример: `evidence_count: { "value": 47, "confidence": "high" }`

## Описание методологии в тексте диссертации

Типовая структура раздела «Методы исследования»:
1. Общая стратегия исследования
2. Объект и предмет исследования
3. Методы сбора данных
4. Методы анализа данных
5. Валидность и надёжность
6. Этические аспекты (если применимо)
