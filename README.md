# PhD Thesis Butler · 俄语学术写作助手

把自己写好的中文段落变成学术俄语，保留每个条件、数字和引用。PTB 在你熟悉的 AI 客户端里提供写作知识卡，陪你从安排章节一路走到定稿前的逐句核对。

**[查看产品首页](https://tanue-hou.github.io/phd-thesis-butler/) · [配置你的客户端](docs/clients.md)**

### 一次委托，从中文原稿到俄语终稿

选中一段原稿，说“帮我翻译成俄语，然后润色和核对”。在 Codex CLI 中，助手会依次完成改译、编辑和核对。交回的稿件附有编辑依据，你可以点开查看为什么保留某个限定词，或为什么删去一句多余的自我评价。

> **中文原稿**　方法 B 仅用于检查误差。  
> **俄语示例**　Метод B используется только для проверки погрешности.

这里的 *только* 界定方法 B 的职责。润色保留这层意思，正如写结果时要保留真实的性能下降和不显著结果。[阅读编辑原则](docs/editorial-policy.md)

### 也可以从一个更小的问题开始

- **规划章节**　用结构卡梳理每一章要回答的问题。
- **比较研究**　对照两种方法的试验条件、验证方式和可比范围。
- **核对证据**　检查措辞是否与手头的证据相称，列出需要回原表确认的事项。

向管理员领取 12 位个人密钥，在自己的客户端保存一次即可。支持 Codex、Claude Code、Antigravity 和 DeepSeek Harness 的接入配置。[分客户端接入教程](docs/clients.md) · [管理员部署与本地测试](docs/operations.md)
