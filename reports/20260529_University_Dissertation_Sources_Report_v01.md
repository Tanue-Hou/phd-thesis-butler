## 三、推荐实施方案

### 最优路线：disserCat + dissovet.msu.ru + disser.spbu.ru 三源并行

| 来源 | 预估论文量 | 免费 авторефераты | 优先学科 |
|------|-----------|------------------|---------|
| **disserCat** | 440,000+ | ✅ 全部免费 | 全学科覆盖，按 ВАК 代码分类遍历 |
| **dissovet.msu.ru** | 5,000-15,000 | ✅ 附件 PDF 可下载 | 理科/文科/医学/工程 |
| **disser.spbu.ru** | 5,000-10,000 | ✅ 需进一步确认 | 全学科 |

### 技术路线

```
Phase 1: 验证数据获取
  1.1 从 disserCat 按选定 ВАК 代码搜索 → 提取论文元数据
  1.2 下载 авторефераты PDF
  1.3 从 dissovet.msu.ru 按分页获取论文 → 下载附件
  1.4 从 disser.spbu.ru 解析已答辩列表

Phase 2: 适配抽取管线
  2.1 确认现有 AREF 抽取管线对 disserCat 来源的兼容性
  2.2 添加 source_university, source_platform 字段
  2.3 分学科适配分类体系

Phase 3: 批量扩展
  3.1 按优先级遍历 ВАК 代码
  3.2 批量下载 + 抽取
  3.3 质量审计 + 合并
```
