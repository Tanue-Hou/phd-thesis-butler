## 二、各源技术方案

### МГУ — dissovet.msu.ru

| 项目 | 详情 |
|------|------|
| API | `https://dissovet.msu.ru/api/dissertations` → 所有论文元数据 JSON (5.4MB) |
| 附件下载 | `https://dissovet.msu.ru/file/dissovet-docs/{uuid}` → PDF |
