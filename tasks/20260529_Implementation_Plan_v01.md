## 技术方案

### МГУ (明轩负责)

| 步骤 | 方法 |
|------|------|
| 1. 获取元数据 | `curl https://dissovet.msu.ru/api/dissertations` → JSON |
| 2. 筛选年份 | `announcedDate` 字段过滤 2023-2026 |
| 3. 提取学科 | `industryName` 字段 → 映射为学科文件夹名 |
| 4. 获取文件 | 遍历每篇的 `/dissertation/{code}` 页面 → 提取 `/file/dissovet-docs/{uuid}` → PDF |
| 5. 下载保存 | 按 `学科/作者/` 结构存储 |

### СПбГУ (知远负责)

| 步骤 | 方法 |
|------|------|
| 1. 获取列表 | 遍历 `proshedshie-zashchity-dissertatsij.html?start=N` |
| 2. 筛选年份 | 访问每篇详情页 → 提取答辩日期 → 过滤 2023-2026 |
| 3. 提取学科 | 从 `кандидата XXX наук` 行提取学科名 |
| 4. 下载 PDF | 从详情页提取 `Диссертация (.pdf)` 和文件链接 → 下载 |
| 5. 保存 | 按 `学科/作者/` 结构存储 |

### BMSTU (思远处理)

已有 647 PDF / 327 篇，用已有 metadata.json 提取学科信息，重新组织目录结构。

## 文件命名规则

- 作者文件夹: `Фамилия_Имя_Отчество` (拉丁转写，无空格)
- 论文全文: `диссертация.pdf`
- 摘要: `автореферат.pdf`
- 元数据: `meta.json`
