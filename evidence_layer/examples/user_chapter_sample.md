# Глава 2. Математическая модель и метод оценки состояния

## 2.1. Введение

Оценка технического состояния трансмиссии мобильных машин является актуальной
задачей, поскольку внезапные отказы приводят к значительным经济损失ам и
простою оборудования. Традиционные методы диагностики основаны на анализе
виброакустических сигналов, которые несут информацию о текущем состоянии
элементов передачи.

## 2.2. Динамическая модель трансмиссии

Рассматривается многоступенчатая зубчатая передача, динамика которой описывается
системой нелинейных дифференциальных уравнений. Основные параметры модели
включают приведённую жёсткость зацепления, коэффициент демпфирования и
моменты инерции звеньев.

Уравнения движения записываются в стандартной форме:

    M * q'' + C * q' + K(t) * q = F(t)

где M — матрица масс, C — матрица демпфирования, K(t) — переменная матрица
жёсткости зацепления, зависящая от угла поворота.

Для оценки неизвестных параметров модели (жёсткость, демпфирование) используется
расширенный фильтр Калмана (EKF). Выбор EKF обусловлен его вычислительной
эффективностью по сравнению с UKF при приемлемой точности для данной задачи.

## 2.3. Алгоритм расширенного фильтра Калмана

Процедура EKF состоит из двух этапов: предсказание и коррекция.

На этапе предсказания производится линеаризация нелинейной модели относительно
текущей оценки состояния. Матрица Якоби вычисляется аналитически для модели
зубчатой передачи.

Адаптация матрицы шума процесса позволяет учесть неопределённость модели,
возникающую из-за приближённого характера линеаризации.

## 2.4. Извлечение признаков из вибросигналов

Измеряемый вибросигнал проходит предварительную обработку: фильтрация,
децимация, вычисление огибающей. Из спектра огибающей извлекаются
характерные частоты дефектов, которые используются как входные данные
для фильтра Калмана.
