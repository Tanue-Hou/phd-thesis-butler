# Пример структуры диссертации: Оценка технического состояния трансмиссии мобильных машин

## Глава 1. Обзор современных методов диагностики трансмиссии

### 1.1. Классификация дефектов элементов трансмиссии
- Типы дефектов: зубчатых передач, подшипников, валов
- Характерные признаки в виброакустических сигналах

### 1.2. Методы анализа вибросигналов
- Временной анализ (статистические показатели, огибающая)
- Частотный анализ (FFT, кепстральный анализ)
- Временно-частотный анализ (вейвлет-преобразование, STFT)

### 1.3. Методы оценки состояния на основе моделей
- Модельно-ориентированные подходы
- Фильтры Калмана (EKF, UKF) для оценки параметров
- Сравнение подходов: модельные vs. data-driven

### 1.4. Постановка задачи исследования
- Необходимость метода онлайн-оценки состояния трансмиссии
- Ограничения существующих подходов

## Глава 2. Математическая модель и метод оценки состояния

### 2.1. Динамическая модель трансмиссии
- Уравнения движения многоступенчатой передачи
- Параметры модели: жесткость зацепления, демпфирование

### 2.2. Формулировка задачи фильтрации
- Вектор состояния и вектор наблюдений
- Нелинейность модели → необходимость EKF/UKF

### 2.3. Алгоритм расширенного фильтра Калмана
- Линеаризация модели
- Предсказание и коррекция
- Адаптация матрицы шума

### 2.4. Идентификация параметров из вибросигналов
- Извлечение признаков из спектра
- Связь параметров модели с измеряемыми сигналами

## Глава 3. Экспериментальные исследования

### 3.1. Стенд и методика эксперимента
- Описание испытательного стенда
- Режимы нагружения

### 3.2. Результаты оценки состояния
- Точность оценки параметров при различных дефектах
- Сравнение EKF с эталонными измерениями

### 3.3. Анализ чувствительности
- Влияние уровня шума
- Влияние частоты дискретизации
